# 🚀 Smart Companion

Smart Companion is a gamified productivity web app built with Next.js.  
It helps users complete tasks, earn XP, and stay motivated — with AI-powered task suggestions.

---

## ✨ Features

- ✅ Predefined productivity tasks
- 🎯 XP reward system
- 🔊 Voice feedback ("Good Job!")
- 🤖 AI-generated task suggestions (Ollama + Qwen 2.5)
- ⚡ Fast Next.js frontend
- 🌐 Deployable on Vercel

---

## 🛠 Tech Stack

- Next.js 14+
- React
- TypeScript
- Ollama (Local AI)
- Qwen2.5:3B model
- Vercel (Deployment)
